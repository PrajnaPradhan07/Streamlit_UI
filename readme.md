## 📌 Project Overview

This project is a Machine Learning web application that predicts California housing prices using a Linear Regression model built with Scikit-Learn and deployed using Streamlit and Render.

---

## ✨ Features

✅ House Price Prediction

✅ Interactive Streamlit UI

✅ Machine Learning Model using Linear Regression

✅ Model Serialization using Joblib

✅ Cloud Deployment using Render

✅ GitHub Integration

## ⚡ Installation

```bash
git clone https://github.com/PrajnaPradhan07/Streamlit_UI.git

cd Streamlit_UI

pip install -r requirements.txt

streamlit run california_app.py
```
